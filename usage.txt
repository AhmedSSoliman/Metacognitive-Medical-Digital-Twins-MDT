### **Python API Usage**

#### **Import and Use Components**
```python
# Example: Use components programmatically
from models.mdt_model import MedicalDigitalTwinModel
from core.cognitive_streams import CognitiveStreamParser
from rewards.composite_engine import CompositeRewardEngine
from config.configs import ModelConfig, CognitiveArchitectureConfig, GRPOConfig

# Initialize
model_config = ModelConfig()
model = MedicalDigitalTwinModel(model_config, use_demo_model=True)

# Generate response
clinical_query = "72 yo male with HR 125, BP 85/50, Lactate rising from 1.8 to 3.2"
response = model.generate(clinical_query, max_length=512)
print(response)

# Parse streams
cog_config = CognitiveArchitectureConfig()
parser = CognitiveStreamParser(cog_config)
streams = parser.parse(response)

print("Clinical Reasoning:", streams.think)
print("Patient State:", streams.patient_state)
print("User Belief:", streams.user_belief)

# Validate
is_valid, error = parser.validate(streams)
print(f"Valid: {is_valid}, Error: {error}")
```

---

#### **Batch Processing**
```python
import pandas as pd
from tqdm import tqdm

# Load cases
cases = pd.read_csv("clinical_cases.csv")

# Process batch
results = []
for _, case in tqdm(cases.iterrows(), total=len(cases)):
    response = model.generate(case['query'], max_length=512)
    streams = parser.parse(response)
    
    results.append({
        'case_id': case['id'],
        'response': response,
        'think': streams.think,
        'patient_state': streams.patient_state,
        'user_belief': streams.user_belief
    })

# Save results
pd.DataFrame(results).to_csv("batch_results.csv", index=False)
```

## **8. TROUBLESHOOTING**

### **Common Issues and Solutions**

#### **Issue: Tests Fail**
```bash
# Solution 1: Check Python version (requires 3.8+)
python --version

# Solution 2: Verify dependencies
pip check

# Solution 3: Reinstall dependencies
pip install --force-reinstall -r requirements.txt

# Solution 4: Check CUDA
python -c "import torch; print('CUDA:', torch.cuda.is_available())"
```

---

#### **Issue: Training Fails - Out of Memory**

**Solution 1: Reduce Batch Size**
```python
# Edit config/configs.py
@dataclass
class SFTConfig:
    batch_size: int = 2  # Instead of 4
    gradient_accumulation_steps: int = 16  # Instead of 8
```

**Solution 2: Use Smaller Model**
```bash
# Use demo model for testing
python main.py --train-sft --use-demo --max-patients 10
```

**Solution 3: Clear GPU Cache**
```python
python -c "import torch; torch.cuda.empty_cache()"
```

---

#### **Issue: Training Killed During chartevents**

**Solution: Already fixed in updated code**
```python
# The updated data/mimic_processor.py uses chunked reading
# This prevents memory overflow

# Verify you have the latest version:
grep -n "chunk_size=1000000" data/mimic_processor.py

# Should show: chunk_size=1000000 in load_chartevents_for_stays
```

---

#### **Issue: MIMIC-IV Files Not Found**

**Solution 1: Check Path**
```bash
# Verify path in config
python -c "
from config.configs import DataConfig
config = DataConfig()
print('MIMIC path:', config.mimic_root_dir)
"

# Check if path exists
ls -lh mimiciv/3.1/icu/
```

**Solution 2: Update Configuration**
```python
# Edit config/configs.py
@dataclass
class DataConfig:
    mimic_root_dir: str = "YOUR_ACTUAL_PATH"  # Update this
```
